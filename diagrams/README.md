# Diagrams Workspace

This folder contains architecture/workflow diagrams and related working artifacts for the project.

## Files

- `ROLE_LEGEND.md`: Shared role definitions used by all diagrams.
- `01_PLATFORM_WORKFLOW.md`: Platform-wide role-based workflow (all phases).
- `02_PLATFORM_SEQUENCE.md`: End-to-end role-centric sequence diagram.
- `03_AUTH_RBAC_WORKFLOW.md`: Deep dive for authentication, tenant context, and RBAC.
- `04_CONTENT_LIFECYCLE_WORKFLOW.md`: Deep dive for authoring, review, publish, and lifecycle controls.
- `05_CUSTOMER_PUBLIC_CONSUMPTION_SEQUENCE.md`: Deep dive for customer/public access, feedback, and analytics loop.
- `06_DETAILED_LOGIC_AND_EXECUTION_PLAN.md`: Rule-level logic, decision tables, state transitions, and execution plan.
- `SOURCE_MAPPING.md`: Code paths used to build these diagrams.
- `phases/README.md`: Endpoint-level phase packs (`P0` to `P7`) organized into phase folders, plus `phases/TRACEABILITY_MASTER.md` for side-by-side cross-phase mapping.
